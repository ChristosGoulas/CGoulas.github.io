# Christos Goulas — Terminal Portfolio

A tiny terminal-style personal page that introduces me to the internet in the most low-effort, mildly creative way possible.

This is not a startup. It is not an enterprise platform. It is simply a small public page with a shell-inspired UI, a few commands, and a bit of personality.

## What is this?

This project is a simple personal landing page built with React and Vite, styled to look like a terminal. It includes a few fake commands such as:

- `whoami`
- `whoami -verbose`
- `top`
- `ping`
- `exit`

The goal is just to make a clean, memorable intro page without taking it too seriously.

## Why does it exist?

Because sometimes the easiest way to say "hey, I'm Christos" is to build a tiny command-line style page and let people explore it casually.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Build for production

```bash
npm run build
```
